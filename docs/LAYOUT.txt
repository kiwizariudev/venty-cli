DATA FLOW (one message)
-----------------------

  you > "make hello.py with hello world and run it"
            |
            v
      [build_system_prompt(ACTIONS, CONFIG) + memory + history]
            |
            v
      POST /v1/chat/completions  (Bearer API_KEY, stream=true)
            |
            v  (spinner while streaming)
      raw JSON string assembled from SSE tokens
            |
            v
      extract_first_json()
            |
            +-- action: "task_plan"
            |       steps[0]: os_write_file ["hello.py", "print('hello world')"]
            |       steps[1]: os_run_python  ["hello.py"]
            |       suggestions: ["add error handling", "run again"]
            |
            v
      handle_task_plan()
            |
            +-- step 1: execute_action("os_write_file", [...])
            |       → resolve_path("hello.py") → data/sandbox/hello.py
            |       → open(path, "w").write(content)
            |       → log_action(...)
            |
            +-- step 2: execute_action("os_run_python", [...])
            |       → subprocess.run("python data/sandbox/hello.py")
            |       → stdout captured + displayed
            |
            v
      show_suggestions(["add error handling", "run again"])
            |
            v
      user types "2" → "run again" selected automatically


STARTUP SEQUENCE (python cli.py)
---------------------------------

  1. load_config()          read data/config/settings.json
  2. apply_theme()          load ANSI color codes
  3. load plugins           extensions/plugins/*.py → ACTIONS
  4. print_banner()         cat + logo + provider/model box
  5. check LLM connection   GET base_url (timeout 5s)
  6. _start_bridge()        if enable_bridge: npm start in bridge/
  7. _check_engine()        check engine/venty_engine[.exe] exists
  8. REPL loop              input → ask_venty → execute → suggestions

WEB DASHBOARD (bridge/)
-----------------------

  cd bridge && npm start   (or ask Venty: bridge_start)
       |
       v
  Express server  http://localhost:7432
       |
       +-- GET  /api/status       provider + model info
       +-- GET  /api/config       settings (key masked)
       +-- POST /api/config       update settings
       +-- GET  /api/history      last 100 conversation turns
       +-- GET  /api/stats        action usage statistics
       +-- GET  /api/action-log   full action history
       +-- GET  /api/memory       saved notes
       +-- GET  /api/logs         log file contents (type + lines params)

  Dashboard tabs:
    Overview   — stats cards, top actions bar chart, recent logs
    Logs       — venty.log / errors.log / sessions.log with auto-refresh
    Actions    — filterable action history table
    Memory     — saved notes by category
    History    — conversation history
    Config     — live config editor with save
